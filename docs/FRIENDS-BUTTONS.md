# Friends shelf

Edit `data/friends.toml`. The `groups` array is intentionally empty until friend entries are supplied. Add groups and 88×31 buttons when ready.

Example structure:

```toml
title = 'Friends & stuff'

[[groups]]
title = 'Friends'

[[groups.buttons]]
name = 'Display name'
image = 'https://example.com/button.gif'
url = 'https://example.com/'
```

Replace the example name and URLs with confirmed details. Button images are displayed at 88×31.
