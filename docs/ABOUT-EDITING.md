# Editing the profile

- Main profile copy: `content/about.md`
- Focus areas and off-duty section: `data/about.toml`
- Team roster: `data/team.toml`
- Friends shelf: `data/friends.toml`
- GitHub and Telegram: `hugo.toml`

Use `hugo server` for local preview. The production workflow builds and deploys the static site through GitHub Pages.
